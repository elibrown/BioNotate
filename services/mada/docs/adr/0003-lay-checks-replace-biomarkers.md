# Use lay Checks from a closed catalogue, not the biomarker thresholds

The original `rules.md` included a `BIOMARKER_USER_GUIDE` with lab and sensor thresholds such as CBC, CRP, urine proteomics and optic nerve width. A Responder with no medical training can't measure those in an emergency, so the guide was deleted and the agent doesn't use it. Instead, the agent asks for Checks the Responder can do on the spot, such as GCS, a pulse count or a photo of a rash. It may ask only for Checks in `checks.md`, so it can't invent an assessment. Apart from GCS, which comes from the official Glasgow "Do it this way" aid, the Checks are placeholders marked `UNVALIDATED`. Real detection criteria and thresholds will come later. Until then, numeric answers are checked only to see if they're physically possible, and they never set Severity.
